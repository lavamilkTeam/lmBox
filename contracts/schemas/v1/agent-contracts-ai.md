# AI 任务协议

先读[共享协议说明](../../agent-contracts.md)。`ai-request.schema.json` 与 `ai-response.schema.json` 定义本机 AI 任务边界；三端手工映射通过公共入口和样例校验。

请求携带协议版本、工程标识、请求标识、输入版本和 `video/agent` 能力。`inspect` 读取实际可用配置；`start` 创建原生任务；`status/cancel/artifact` 必须匹配创建时的工程、任务、能力和输入版本。请求成功不代表任务已成功；终态、事件和产物由 Rust 保管。进程内任务记录不代表已有工程持久化或重启恢复。

视频请求使用 lmBox 节点结构：节点标识、类型、输入、画布位置；引用输入为 `{nodeId, outputIndex}`。ComfyUI 的 `class_type` 和端口数组由 Python 私有适配转换。凭据不属于工作流；后端配置注入云端 Partner 或自定义 API 节点凭据。

Agent 请求包含任务文字、步骤上限及 UTF-8 文本附件。工具只能访问所属任务工作目录。附件最多 16 个、总计 1 MiB；产物通过注册标识获取，单个最多 32 MiB，不接受客户端路径。界面取消请求后继续查询原任务状态，不能以 HTTP 中止冒充云端任务取消。

验证覆盖版本/身份拒绝、任务隔离、取消、真实协议及可辨识外部服务替身。外部模型未配置或未实测时不能声称云端推理已验证。

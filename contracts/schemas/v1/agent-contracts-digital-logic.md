# 数字逻辑会话协议

先读[共享协议](../../agent-contracts.md)。`digital-logic-request.schema.json` 与 `digital-logic-response.schema.json` 定义 Rust 数字逻辑核心的版本化数据边界；Rust、TypeScript 类型为手工映射。状态按工作区隔离，不传递 DOM、Worker、WASM 或仿真内部对象。

- 请求包含 `schemaVersion: 1`、工程/请求标识、`inputRevision` 和有限命令。首次 `load` 绑定工程；之后拒绝其他工程及较旧输入版本，允许相同或更新版本。响应原样关联这三个身份字段，调用端只接受当前请求的精确身份。
- `load` 提供节点、连线和输入初值；缺省输入初值为 `0`。信号为 `0/1/X/Z`，`set_input` 只允许 `0/1`。节点类型和目标端口由 Rust 校验；线路源为节点单输出，`targetPort` 标识目标数字输入，位置与外观不参与协议。
- `step` 执行 1–1000 个离散 tick；`reset` 重置当前电路的仿真状态。请求失败不能部分更新原有状态。推进、组合稳定性及字符显示语义归 [Rust 数字逻辑模块](../../../src-rust/src/modules/digital_logic/agent-rust-digital-logic.md)。
- 最多 512 个节点、4096 条连线；工程、请求、节点及连线标识为 1–128 个 ASCII 字母、数字、下划线或连字符。端口名另外允许斜杠以保留 `R/W`，具体名称由核心按节点校验。版本与 tick 为 JavaScript 安全范围内的非负整数。
- 响应返回每节点输出、每目标端口输入、字符显示及有界诊断。显示固定两行、每行 16 个 Unicode 字符，光标为可见位置 `0..31` 或 null，显示开关独立返回。诊断最多 512 条，每条 1–4096 字符；未知/悬空信号保持 `X/Z`，不能显示为已确定电平。
- Worker 传输承载有上限的 JSON 文本；反序列化或核心拒绝通过请求 Promise 的错误返回，不伪造成功响应。响应必须完整验证版本、身份、计数器、信号及数组/字典边界。

验证从 Rust 公开会话接口、共享 schema 和前端平台公开入口覆盖请求拒绝、序列化、顺序、失效响应、终止及真实 WASM 链路；传输成功不等同于电路物理验证。

# 协议：文件导入协议

先读 [语言说明](../../agent-contracts.md)；维护规则与隐私要求见根规范。

## 职责与边界

覆盖 import v1 和文件级诊断；Worker 关联信封不等于长任务协议。

不得加入业务或算法实现；协议变更同时阅读并更新受影响两端映射与样例。

## 行为约束

浏览器和未来原生适配共享文件级导入结果：`protocolVersion` 为 1，每层包含名称、原始大小、角色，以及互斥的 graphics v2 IR 或结构化诊断（代码、消息、可用时的行号）。Worker 信封附带请求 ID 用于匹配结果；该短请求不代表已建立工程/长任务协议。

## 验证

运行受影响语言的检查；schema 通过不等于几何语义正确。保持版本接受/拒绝行为一致，不声称尚未建立的自动生成工具已运行。

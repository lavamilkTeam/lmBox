# 协议：预览与编辑协议

先读 [语言说明](../../agent-contracts.md)；维护规则与隐私要求见根规范。

## 职责与边界

覆盖 preview v1、编辑、优化、产物和桌面传输；算法实现见 Python 模块。

不得加入业务或算法实现；协议变更同时阅读并更新受影响两端映射与样例。

## 行为约束

- 所有请求包含 `protocolVersion` 和可关联的请求标识。长任务还包含 `projectId`、`jobId`、`inputRevision`；响应/事件必须携带相同关联信息。
- 请求区分工程读取/修改、模型构建、检查、切片等业务操作；不提供任意 shell 命令或任意 Python 函数执行接口。
- 进度事件包含阶段及可用时的完成量；无法测量时不编造百分比。终态成功、失败、取消互斥且只确认一次。
- 错误使用稳定代码、简短消息和结构化上下文。完整技术诊断进入日志，不能用原始 traceback 填满用户面板。
- JSONL 标准输出仅传小型协议消息。大型 IR、二维轮廓、网格、STL、G-code 通过 Rust 分配的任务目录交换；结果以产物清单、校验摘要、格式版本引用。
- Python 仅访问本任务明确授权的输入/输出文件。前端使用 Rust 生成的产物标识，不自行拼接任意本地路径。
- 二维轮廓和三维模型来自同一个计算输入版本，记录算法版本、单位、容差及尺寸。切片结果记录所用模型摘要、切片配置和切片器版本。

- `preview.schema.json` 定义模型请求：版本、工程/任务 ID、输入修订、graphics v2 IR，以及毫米制厚度、边距、补偿和显式镜像。相同身份必须贯穿进程结果与浏览器结果。
- Rust 将请求写入任务目录的 `input.json`，通过 JSONL 传身份；Python 只返回匹配身份和固定 `mesh.json` 产物名称。错误通过 `error` 消息返回，不返回半成品。
- 网格产物包含扁平 XYZ 顶点、三角索引、二维环，以及毫米 bounds、体积、孔数、面数和容差。预览参数变化后旧修订产物失效，显示参数不改变输入修订。
- 当前为单次本地预览协议；不包含 STEP、工程存储、切片或可打印性保证。


### preview v1 编辑扩展

这些均为可选字段，旧四参数请求保持原行为；共享样例为 `fixtures/v1/editing.json`。

- `settings.design` 一旦提供必须完整：生成钢网或底板、外框方式、独立边宽、四角样式/尺寸、PCB 厚度/间隙、底层厚度、卸板槽、取件斜口及整层优化。可选 `cornerStyles` 为四角分别覆盖 R/C 样式，未提供时沿用统一 `cornerStyle`。范围和必填字段以 schema 为准。
- `outline` 是已解析的 graphics v2 板框，单位与主层一致；不携带路径或原文件。未提供时使用主图形包围矩形，界面必须说明此回退。
- `edits` 是唯一实例 ID 的稀疏覆盖，ID 为 `重复行:重复列:对象索引`，从 0 起计数。固定流程为绕源面积中心缩放/旋转、位移、局部补偿，再优化；删除可恢复。`optimization` 覆盖是完整参数组，未提供才继承整层配置。
- 优化字段包括开孔缩放百分比、内孔圆角、网格启用/阈值/最大格孔尺寸/筋宽、密孔错排启用/间隙阈值/位移及缩小百分比、上口相对接触面的喇叭孔比例（100 为直壁）。制造语义和顺序由引擎文档定义。
- 网格可附加 `objects`：实例 ID、已编辑轮廓环、删除标记，用于命中测试与高亮。坐标已应用镜像，渲染器不可重复镜像。`contours` 为钢网接触面或底板顶缘截面；`summary.algorithmVersion` 记录计算版本。
- `exportFormat` 可为 stl/svg/dxf；仍使用独立工程/任务/输入版本身份。Python 固定 `mesh.json` 可附带导出文本，Rust 验证格式后将其作为响应 `artifact: {format, content}`。适配只接受当前版本并由受控下载入口落盘，不接受任意输出路径。
- 该扩展仍不包含完整工程存储、STEP 或切片协议。

- 优化组新增可选布尔 `inverseTaper`，缺省为 false。比例为 P 时，上口按 P/100 缩放；开启后下口按 (200-P)/100 缩放，关闭时下口保持 100%。开启时 P 必须小于 200；整层与局部使用相同字段。比例基于编辑、优化和补偿后的孔形，表示板厚方向的两端截面。

### preview v1 XY 缩放扩展

- 优化组新增可选 `xyMode`（`off`/`upper`/`whole`/`opposed`，缺省 `off`）、`xyScaleX`（缺省 80）和 `xyScaleY`（缺省 120），单位为百分比，范围 10–200；`opposed` 模式两比例均须小于 200。旧请求不改变形状。
- `upper` 保留下半部，上半部 Y 按比例拉伸，X 因子从中心 100% 渐变至顶端指定值；`whole` 为整体缩放；`opposed` 的上下半部 Y 分别按指定值及 `200-P` 拉伸，X 因子按拉伸后的 Y 坐标从底端 `200-P` 连续线性渐变到顶端指定值。分界与缩放原点为优化前当前焊盘包围框中心，上为 +Y，轴为画布 X/Y；中心没有宽度台阶。算法 0.2.4 修正了此前分区常量缩放造成的台阶。与 `taper`/`inverseTaper` 的板厚方向截面变换独立并可叠加，顺序详见引擎说明。
- `fixtures/v1/xy-scaling.json` 为选中单个焊盘应用 XY 优化的跨端样例，三端测试共用；未选中图形继续继承整层设置。

IPC 入口位于 `desktop/tauri/`，改动时同时阅读 [桌面宿主说明](../../../desktop/tauri/agent-rust.md)。

- 桌面 `preview_prepare`/`preview_cancel` 使用已有 projectId、jobId 管理本进程内的任务登记；`preview_run` 使用完整 preview v1 请求与响应。IPC 不改变制造字段或协议版本，不代表持久工程/任务协议已经实现。
- 先登记再运行防止取消竞态，所有终态继续由完整版本身份校验；导出只把已经验证的文本交给原生保存对话框，取消保存不能记为成功。

## 验证

运行受影响语言的检查；schema 通过不等于几何语义正确。保持版本接受/拒绝行为一致，不声称尚未建立的自动生成工具已运行。

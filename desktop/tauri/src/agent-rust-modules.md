# 桌面安装模块适配

先读[桌面语言说明](../agent-rust.md)和[安装管理说明](../../modules/agent-rust.md)。`modules.rs` 不实现下载、解压或业务计算，只将独立分发 crate 的安装快照适配给宿主。

`modular` 构建从可信安装根加载启动快照，要求与宿主版本匹配；使用 Tauri 注册的本地 `tauri` URI 协议按登记的 UI 文件提供资源，保留本地 IPC 来源、CSP 和禁止任意路径读取的约束。不存在的文件返回 404，不回退未安装资源。普通整包构建沿用嵌入资源及原有运行库定位。

`module_status` 返回模块版标识和已安装功能 ID；前端从平台公开入口读取，不自行读磁盘。每个计算 IPC 另校验功能安装状态；功能 UI 和共享运行库登记分别检查。宿主不会接受来自前端的可执行程序路径。

AI/CFD 的未安装运行环境允许基础宿主启动，调用该能力时明确失败。安装快照在整个主程序进程中固定，更新不会覆盖运行中的前端文件、Python worker 或 Fortran 运行库。安装器补装或卸载后重启主程序生效。

执行桌面 fmt/Clippy/tests，并以 `--features modular` 另检查模块版。原生 GUI、本地 Worker、Fortran 计算及跨平台行为须实际验证，不能从编译结果推断。

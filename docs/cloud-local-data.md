# 云端与本地的数据边界

本文区分当前实现与后续接入方案。它不是数据库已部署、统一登录已完成或数据已经同步的声明。

## 当前实现

- 完整前端通过 `frontend/platform/desktop` 适配浏览器 HTTP 与桌面 IPC；尚未接入统一账户会话，完整应用按访客启动。账户表单不发送凭据或模拟登录成功。
- `scripts/cloud` 只打包完整静态网页和 WASM，不包含生产业务服务或数据库。
- `scripts/web-agent` 包含单操作员 HTTP 宿主和 Rust/Node Agent，使用服务端 Basic 认证。该认证不是统一账户登录，也不能作为多用户数据隔离。
- Agent 任务和对话记录主要在内存，任务文件和防重放标记保存在宿主数据目录；`LMBOX_WEB_DATA` 指向网页宿主文件目录，不是数据库连接。未实现可恢复的本地会话库、云端工程库或自动同步。
- 独立管理项目的统一账户库保存用户 UUID、外部身份、平台及成员关系。其管理库保存管理员会话、模型端点和 token 账本；两者通过不同服务端连接配置分开。
- 管理项目的账户模块目前只提供数据库就绪/状态检查，没有可供 lmBox 使用的统一登录、登出和会话 API。官网已有会话也不能直接当作 lmBox 或管理站会话。
- 模型网关以服务凭据识别 `lmbox-web` 应用，按应用统计 token；当前账本没有终端用户分账。不得把浏览器提交的用户标识直接当作计量身份。

## 三个独立维度

| 维度 | 值与用途 | 不改变的内容 |
| --- | --- | --- |
| 使用方式 | 轻松模式：纯 Agent；专业模式：完整工作台加辅助 Agent | 登录身份、数据库归属、资源权限 |
| 运行位置 | 本机宿主或云端宿主，由可信启动配置决定 | 不由页面 URL、用户是否登录或卡片选择猜测 |
| 账户状态 | 未知、访客、已登录，由账户会话适配器提供 | 网络错误不等于未登录；切换界面不代表登录成功 |

本机用户也可以登录云端账户和使用云端模型；这不会自动上传本地工程。云端用户选择专业模式也不会获得本机文件或工具访问权。模型路由与工程存储位置分别配置。

## 目标存储归属（尚未实现）

| 数据 | 所有者与建议存储 | 访问方式 |
| --- | --- | --- |
| 统一身份、身份绑定、平台成员关系 | 账户服务的现有 PostgreSQL 账户库 | lmBox 服务端通过经过授权的账户接口获取用户 UUID；不复制密码库 |
| 管理员会话、上游模型密钥、服务端 token 账本 | 独立管理服务的现有 PostgreSQL 管理库 | 管理员 API 或模型网关；浏览器和桌面分发包不携带网关服务密钥 |
| 云端工程、对话、任务元数据 | lmBox 云服务独立业务库（PostgreSQL），独立数据库角色 | 仅云服务访问；文件放受权限保护的产物存储，库内记录归属和引用 |
| 本机工程索引、对话、偏好与任务元数据 | Rust 本机宿主的 SQLite 与用户数据目录 | 经 Rust 公开接口；大文件留在工程目录，不把 SQLite 文件放源码仓库 |
| 桌面登录凭据或用户自带模型密钥 | 操作系统凭据存储 | 本机平台适配读取；不存浏览器 localStorage、偏好表或工程文件 |

本机记录可有稳定的安装标识和本地工程 UUID，但它们不是云端用户身份。云端每条业务记录必须具有服务端验证的用户归属；任务、查询、取消、附件和下载都校验同一归属，不能仅依赖请求传入的 `projectId`。共享模型网关的应用级密钥继续只保留在服务端。

## 在 lmBox 仓库中落地的顺序

1. 先确定账户服务的公共会话协议，再在 `contracts` 定义运行位置、账户状态及会话结果。区分未认证、服务不可用与检查中；禁止用 Cookie 是否存在推断认证成功。
2. `frontend/platform` 实现浏览器/桌面会话适配；应用注入状态给公共 feature。`features/experience-mode` 只负责模式选择，不接数据库、不授予权限。当前访客默认值必须在真实适配接入时替换。
3. 本地持久化由 `src-rust` 的对应业务模块拥有公开接口和私有 SQLite 适配；桌面宿主只提供用户数据目录和凭据访问。开始实现时才新增模块、迁移与模块说明，不为未来能力建立空目录。
4. lmBox 云服务单独提供会话验证、用户隔离和任务工作目录，再增加业务库迁移。现有单操作员 web-agent 包不能直接改为公网多用户服务；前端继续通过同源 API 调用。
5. 个人 token 分账需要管理网关扩展可信调用身份及账本，并由服务端绑定已验证用户 UUID。必须同时保留现有应用维度，不能伪造当前应用级统计为个人用量。
6. 最后实现显式同步：由用户选择工程，上传前检查身份，服务端校验所有权和输入版本，冲突明确返回。退出账户不删除本地工程，云端不可用不自动把在途云任务转为本地重跑。

仓库提交接口契约、代码、迁移脚本、配置模板和测试。真实数据库、备份、用户文件、会话令牌、环境文件与连接串留在各宿主的私有运行目录。管理库和账户库迁移继续归独立管理/账户服务维护，lmBox 不跨仓库导入其私有实现，也不直接修改其表。

## 验收要求

- 本机访客可以继续使用已实现的本地能力；模型未配置时如实反馈。
- 账户未知或检查失败不被标成已登出；认证成功不自动授予管理员权限。
- 云端测试用两个不同用户验证工程、任务、附件、取消和下载隔离；浏览器不能伪造计量用户。
- 本地和云端持久化分别测试重启、迁移与失效凭据；不以页面内存恢复代替重启持久化验收。
- 同步和按用户计量在实现前保持未开放，不用前端状态模拟成功。

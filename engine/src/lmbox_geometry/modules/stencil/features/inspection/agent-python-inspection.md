# Python：网格检查

先读 [语言说明](../../../../../../agent-python.md)；维护规则与隐私要求见根规范。

## 职责与边界

公开入口接收 contracts 网格，执行闭合、法向、退化面和体积检查。

不重新建模、编码或读写产物；只输出结构化检查摘要/错误。实体有效不等于已通过切片可打印性验证。

## 行为约束

- 网格需要检查法向、闭合性、非流形边、退化三角形、尺寸与孔洞保留情况。几何有效不能替代切片后的可打印性验证。

- `features/inspection` 只接收 contracts 中的网格数据，校验闭合性、法向、退化面和体积；`application` 协调生成、检查及可选导出，再由 `runtime/artifacts` 原子发布任务内固定产物。

- inspection 校验有限坐标、闭合、法向、退化面及正体积；直壁网格与解析面积×厚度核对，变截面网格与实体内核体积独立核对。三角面仍限制为 500000。

## 验证

统一检查见 [语言说明](../../../../../../agent-python.md#验证与维护)。验证有限坐标、闭合/法向/退化面、正体积、直壁解析体积和变截面实体体积。

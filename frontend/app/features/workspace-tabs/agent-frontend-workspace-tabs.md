# 前端：工作区页签

先读[平台组装说明](../../agent-frontend-app.md)。公开入口 `index.ts` 提供 `useWorkspaceTabs({ tools, closeHandlers })`；私有状态和行为位于 `lib/`，不包含组件或样式。

- 接受可用功能目录，维护固定“开始”“功能库”、已打开功能顺序及当前页签；同一功能只能打开一次，无效和禁用入口不打开。
- 输出 `active`、`tabs`、`closeConfirmation` 与打开、选择、关闭、确认和取消方法。关闭活动页签选择右邻、左邻或“开始”；关闭后台页签不切换当前页。
- 应用组装层按功能 ID 注入异步 `closeHandlers`。这些页签先显示确认，确认后等待释放完成再移除；等待中禁止重复释放或取消，失败保留错误和页签供重试。无处理器的页签直接移除，不清理领域草稿。
- feature 只依赖 Vue，不导入领域模块、共享 UI 或平台适配。领域公开入口调用由应用组装层注入，视觉、焦点与键盘呈现由工程工具箱 UI 负责。

`tests/` 通过公开入口覆盖去重、邻页选择、异步关闭防重和失败重试；运行 `npm run check`，浏览器页签与 CFD 生命周期测试验证完整交互。

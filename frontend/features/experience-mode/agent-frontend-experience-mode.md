# 使用方式选择功能

先读 [前端结构](../../agent-frontend.md)。`index.ts` 公开 `useExperienceMode`，接收应用提供的响应式账户状态，维护只读 `mode/open`，通过 `select/setOpen` 接收用户操作。不访问账户 API、持久化、领域模块或 UI。

只有明确 `guest` 才自动打开选择；`unknown` 不推断为未登录，`authenticated` 关闭提示。每次访客阶段只自动打开一次，关闭或选择后不因工作区切换再次打断；登录后再次退出可重新提示。页面重载重新选择，关闭默认保留专业模式。手动入口始终可重新打开。

`agent/advanced` 仅决定界面组织，不决定登录身份、模型权限或本地/云端数据归属。应用负责可用模块校验与工作区组装。运行 `npm run check`；公共入口测试覆盖账户状态转换，浏览器测试覆盖选型、关闭、模式切换与草稿保留。

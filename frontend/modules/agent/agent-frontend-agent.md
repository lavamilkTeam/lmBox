# 前端：AI 工作助手

先读 [前端结构](../../agent-frontend.md)。模块入口 `index.ts` 只公开 `AgentWorkspace`；不导入视频或其他业务模块。

## 职责与依赖

- `lib/app` 协调连接检查、文本附件、执行、状态轮询、取消和结果保存；所有文件与通信操作通过 [平台公开接口](../../platform/desktop/agent-frontend-desktop.md)。
- `lib/domain/session/index.ts` 公开会话 store，保存输入草稿、步骤预算、附件、发送轮次及各轮任务身份和结果；不读取本地文件或访问网络。
- `lib/ui/index.ts` 公开模块内部 props/emits 视图；控件复用 [shadcn-vue](../../ui/shadcn/agent-frontend-shadcn.md)，只展示实际连接、任务记录、文本和产物，不执行工具调用。
- `lib/ui/elements` 按需迁入 AI Elements Vue 的消息、对话、输入区和执行记录外观；保持私有，只使用本项目 shadcn 公开入口。固定来源及修改记录见 [NOTICE](lib/ui/elements/NOTICE)，保留原版权声明及 Apache 2.0 全文，随主应用构建发布。组件不含 AI SDK 传输、Markdown 执行、文件读取或凭据；纯文本回答由 Vue 转义。
- 请求和结果使用 [AI 协议映射](../../contracts/agent-frontend-contracts.md)。Agent 模型、工具范围和执行循环由后端定义，界面不能直接获得或设置密钥。

## 会话约束

任务与附件绑定输入版本；运行期间锁定输入。文本附件拒绝重复文件名和路径名称，限制总 UTF-8 字节数为 1 MiB、最多 16 个附件，文件字节读取与限制另由平台负责。步骤预算为 1 至 32；任务只在真实模型配置就绪时可执行。

Pinia 保存单个会话的对话轮次；编辑或发送下一轮保留先前快照与结果。已确认启动后清空输入框和本轮附件，发送下一轮仅引用最后成功任务的 `parentJobId`；失败或取消轮次不进入上下文。后端按任务链构造真实文本上下文，前端不提交自造的助手消息。每个对话最多完成 20 轮，达到上限后明确要求新建对话，不能静默丢弃早期上下文。

切换页签保留草稿与运行任务；卸载只停止轮询，重新进入恢复查询。响应必须匹配工程、请求、任务与输入版本；已结束任务不能回退为运行中，网络异常保留任务以便重试。取消以后台实际状态为准。历史结果下载使用对应轮次的工程、任务和输入版本，不能覆盖当前任务请求。各轮文件工作区独立，历史附件显示为记录，不表示下一轮仍可读取；历史产物依赖后端保留期，失效时报告实际错误。

新建对话只在没有运行、待确认或正在提交的任务时清空当前会话记录与输入；不删除外部文件，不重用旧上下文。回答与执行记录来自实际后端，不宣称流式 token 或未提供的工具细节。

输入区使用 Enter 发送、Shift+Enter 换行，输入法组合期间不发送。收到新结果时仅在用户原本位于底部时跟随滚动，阅读历史时保留位置；滚动按钮返回最新消息。设置面板与窄屏布局归 UI。

附件读取期间显示读取状态并阻止发送，完成后再允许提交；新建对话和离开页签后忽略迟到的附件读取结果。

启动响应丢失时锁定草稿并保留原请求，用户通过“确认任务状态”重发相同请求标识；依赖 Rust 的幂等任务登记，不自动创建新任务重试。平台明确请求尚未发送时解除锁定，允许修改输入。完整页面重载不声明恢复任务；平台为新会话产生请求命名空间。

## 验证

`lib/domain/session/tests` 从公开入口验证输入快照、附件边界、上下文父任务、历史产物身份、对话上限、新建对话、运行锁定、取消状态及过期响应拒绝。运行 `npm run lint:boundaries`、`npm run test`、`npm run build`，浏览器验收归统一 `npm run check`。

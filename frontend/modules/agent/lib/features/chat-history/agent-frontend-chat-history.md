# Agent 聊天记录功能

先读 [Agent 模块说明](../../../agent-frontend-agent.md)。`index.ts` 公开 `useChatHistory`，通过会话 domain 的公开入口管理各聊天的独立状态；不导入 UI、平台或其他 feature。

每条聊天拥有独立工程标识、请求命名空间和会话 store，避免新聊天的输入版本与旧工程冲突。标识由应用调用平台生成并注入。`initialize` 只建立首次聊天；`create/select` 新建或切换，`setQuery` 搜索首轮消息或草稿派生的标题。列表不伪造历史内容，不创建重复空聊天。

任务启动中、运行中或状态待确认时禁止新建和切换；附件读取期间由应用额外禁用。切换保留各自的草稿、步骤预算、附件、消息、任务身份和产物引用，不复制旧聊天的 `parentJobId` 到新聊天。应用在异步调用前捕获所属会话，迟到响应只能更新原会话。

记录存于当前 Pinia 生命周期内，跨工作区和轻松/专业布局保留；刷新页面不恢复。尚未接入本地数据库或云端持久化，不把内存列表称为服务器历史。已有产物仍依赖原生宿主任务保留期。

验证运行 `npm run check`。公共入口测试覆盖草稿隔离、上下文与产物身份、状态锁、搜索和迟到响应；浏览器通过真实 Rust/Node 与可辨识模型夹具验证聊天切换、续聊、下载和取消。

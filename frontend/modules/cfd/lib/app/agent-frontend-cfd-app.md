# 前端：CFD 会话协调

先读 [模块说明](../../agent-frontend-cfd.md)。负责串行请求、轮询、文件适配和任务面板/模型树事件协调；仅调用 feature、domain、UI 与共享 platform/contracts 的公开入口。

每次发送前取当前已确认版本；响应须匹配工程、请求和输入版本，以响应 `revision` 更新下一次请求。轮询不阻塞原生停止与对话框响应，卸载后停止轮询。视口尺寸通过 platform 观察后传给纯 UI，文件读取和保存通过 platform；不在此层运行 CFD 算法或直接访问系统路径。

原生进程终止后仅在用户选择重新连接时先显式关闭会话；关闭成功才清空快照并从版本 0 初始化，普通错误不清空工程。

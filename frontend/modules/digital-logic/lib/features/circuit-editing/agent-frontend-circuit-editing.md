# 前端：逻辑电路编辑功能

先读 [模块说明](../../../agent-frontend-digital-logic.md)。`index.ts` 只公开 `useCircuitEditing`，使用 domain 的目录与电路会话状态；不导入 app 或其他 feature，不包含图片、坐标绘制或样式。

添加、移动、连接、移除节点及移除连线均由本 feature 执行。允许重复门类型，位置必须有限并保留 24 的最小边距。一个输入只允许一个驱动，单输出可以扇出到多个命名输入；无输出元件不能作为连线来源，依据 domain 目录校验；拒绝不存在的门/端口与组合反馈回路，允许经过 D 触发器的反馈及触发器自身回接。添加输入开关初始化其意图值为 0，删除节点清除其所有关联边和输入意图值。校验失败返回错误，由 app 呈现通知。

`useCircuitEditing` 接收由 app 注入的端口坐标查询，使用与显示相同的局部引脚坐标，不导入 UI。移动时以请求位置寻找当前节点入边、出边中最近的水平对齐位置；局部输出坐标可为 null；顶部输入不参与水平吸附。左侧输入端必须在输出端右侧，垂直差不超过 12 个画布单位，且对齐后保留最小边距。等距按连线顺序选择，只调整当前门的 y，不移动邻居；拖出阈值或删除连线后自然解除。缩放不改变画布单位阈值，键盘移动沿用同一入口。合法新连线只按新边对齐目标门；失败连接和无效端口几何不改变位置。

`tests/editing.test.ts` 从 feature 公开入口验证连接约束、清理与同一会话的编辑；`tests/digital-logic.pw.ts` 覆盖真实 UI 的点击/拖动接线、移动、缩放与键盘删除。运行 `npm run check`。

`importDocument` 原子校验并替换会话草稿，拒绝未知版本、重复 ID、多驱动、组合环、无效端口和输入意图；上限 512 节点、4096 连线。文件内容由平台读取，feature 只接收未知值；失败保持原草稿。节点可包含名称与 1–4 倍显示比例，吸附按缩放后的引脚坐标处理。

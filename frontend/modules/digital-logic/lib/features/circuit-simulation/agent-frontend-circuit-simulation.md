# 前端：电路仿真协调

先读 [模块说明](../../../agent-frontend-digital-logic.md)。`index.ts` 只公开 `useCircuitSimulation`，依赖领域草稿及共享协议；会话工厂与可取消的播放调度器由 app 注入，不导入平台、UI 或其他 feature。

每个 Pinia 电路草稿对应一个控制器和持久 Rust 会话，提供展示快照、输入切换、运行/暂停、单步、复位及销毁。节点类型、连线或端口改变时暂停并重新加载；移动位置不影响计算。复位用当前输入开关意图重新加载，清除时钟、触发器和 LCD 状态。算法与控制器指令执行均由 Rust 负责，当前状态不写回草稿。

请求串行执行并携带独立请求 ID 和递增输入版本，只有身份匹配的最新响应才能更新展示；修改电路或输入时立即清除旧快照。失败停止运行并显示真实错误，复位建立新会话以恢复。播放定时器等待上一请求完成，暂停取消后续调度；离开工作区暂停，返回保留快照与会话。控制器 watch 独立于视图生命周期；显式销毁与 HMR 释放 watch、定时器和 Worker，并忽略迟到响应。

`tests/simulation.test.ts` 使用注入的会话和调度器验证串行输入、版本失效、移动/拓扑差异、暂停、恢复、复位及销毁。真实求值链路由 `tests/digital-logic-simulation.pw.ts` 验证；运行 `npm run check`。

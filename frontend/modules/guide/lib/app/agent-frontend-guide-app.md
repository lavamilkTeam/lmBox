# 前端：引导界面协调

先读 [模块说明](../../agent-frontend-guide.md)。`Workspace.vue` 从 domain 公开入口取得目录及草稿，将显示数据传给 UI，并协调添加、移动、连接和删除。可用节点的打开请求通过模块事件交给平台 app；未接入节点不能发起打开。连接失败使用共享主题通知反馈，不显示常驻状态说明或操作成功提示。

页面卸载不清空 Pinia 草稿。刷新或重新启动会新建草稿；不承诺持久化或计算联动。

应用可通过 `installedIds` 注入已安装功能；缺省保留原有目录，传入时仅允许已安装节点打开。分发状态由平台应用拥有，本模块不读取安装目录或安装服务。

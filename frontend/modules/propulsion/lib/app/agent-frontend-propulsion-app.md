# 前端：推进计算协调

先读 [模块说明](../../agent-frontend-propulsion.md)。`Workspace.vue` 组装两个独立 feature，通过 domain 入口取得草稿快照，通过 platform 调用计算和保存。这里不实现数值模型或样式。

修改参数、切换工具或卸载时停止等待并拒收旧响应；原生同步求解无法中断，停止等待不代表终止 Fortran 运算。只有任务、工程和输入版本匹配的成功结果可显示和导出。导出 SVG/DXF 通过相同保存适配并只接受当前有效计算；导出 JSON 同时保留已提交请求及对应结果；取消保存不提示成功，文件操作归 platform。页面重新挂载时从会话 store 恢复草稿与有效结果，不承诺工程持久化。

执行 `npm run check`；覆盖真实计算、非法输入、导出配对、迟到响应、切换和窄窗口。

# 前端：推进设计草稿与任务快照

先读 [模块说明](../../../agent-frontend-propulsion.md)。公开 `useDesignStore`，Pinia ID 为 `propulsion-design`。仅依赖 Vue、Pinia 和共享 contracts；无网络、IPC、文件操作或物理算法。

喷管/喷注器草稿、修订号、待处理任务及结果相互独立。`begin` 创建请求快照并拒绝空缺或非有限数值；`accept` 核对当前工程、任务、修订及响应类型。编辑、重置或取消使待处理任务失效，迟到错误也不能覆盖新任务。结果和已提交请求必须成对保留。初始参数明确标识示例，与共享 fixtures 对照验证。

测试从 `index.ts` 入口验证样例契约、旧结果拒收、会话隔离及重置；执行 `npm run check`。

图纸标题与结构条件保留为独立会话备注，不触发数值输入版本变化；默认结构条件为空，不推断材料、壁厚、公差或冷却形式。

# 前端：推进设计外观

先读 [模块说明](../../agent-frontend-propulsion.md)。`index.ts` 提供数量输入、型面/截面图和数值格式化，`workspace.css` 将所有外观限制于 `.propulsion-workspace`。不依赖 domain、feature、app、platform 或通信契约。表单、折叠区、表格和操作控件通过共享 `ui/shadcn` 公开入口复用；领域布局和绘图样式仍归此目录。

数量输入只做显示单位与 SI 值之间的转换；清空产生非有限草稿，由表单/应用拒绝提交。型面传入纯坐标，轴向与径向保持等比例；流道截面传入内外径，各图独立缩放并明确标记。图形缩放属于呈现，不生成工程尺寸。图形与结果面板不得被 flex 压缩裁切，窄窗口采用纵向滚动。

执行 `npm run check`，并查看真实计算后的宽窄窗口截图。

`EngineeringDrawing`、`drawingSvg`、`drawingDxf` 接收纯绘图数据（求解器点列、尺寸和文字），只执行单位转换、投影和标注；不生成型面。SVG 为 A3 版面并转义全部输入文字；DXF 为毫米单位的双侧离散 POLYLINE 及独立标注图元，不是精确圆弧/样条、关联 CAD 尺寸或加工刀路。弦高误差、公差、外壁和装配几何由设计者另行定义。图纸标记和文字精度不得被解释为制造放行。

图纸只呈现已填写的结构备注及图号；省略缺项说明、空的审核/批准占位和实现细节。保留内轮廓、单位、基准和尺寸，SVG 不添加示例或校核状态横幅。

屏幕预览采用无卡片边框的白色工作区，不设置灰色衬底或内层纵向滚动容器；图纸外框只在导出的 SVG 中保留。

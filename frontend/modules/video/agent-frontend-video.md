# 前端：AI 视频工作流

先读 [前端结构](../../agent-frontend.md)。模块入口 `index.ts` 只公开 `VideoWorkspace`；模块不导入其他业务模块。

## 职责与依赖

- `lib/app` 组装节点视图与任务操作，通过 [平台公开接口](../../platform/desktop/agent-frontend-desktop.md) 读取工作流、请求后端、预览和保存产物；不直接连接 ComfyUI。
- `lib/domain/workflow/index.ts` 公开会话 store 和凭据字段判定。私有 graph 实现负责 API 工作流与 lmBox 文档转换、节点类型/端口/必需输入/循环校验；Pinia 保存草稿、目录、输入版本和任务身份。
- `lib/ui/index.ts` 提供模块内部的 props/emits 界面及视图类型。节点库、画布和参数控件复用 [shadcn-vue](../../ui/shadcn/agent-frontend-shadcn.md)，布局与样式仅在 UI 层。
- 通信使用 [AI 协议映射](../../contracts/agent-frontend-contracts.md)，沿平台适配、Rust 任务协调、Python 执行方向；前端不拥有第三方推理执行器。

工作流导入、保存和 API 导出位于节点库的文件菜单；连接详情与刷新位于设置浮层。画布内的悬浮操作区承载生成、取消、状态恢复及任务错误，不增加模块顶栏或常驻连接报错栏。

## 工作流与任务约束

节点目录来自实际后端；不附带伪造的视频工作流或输出。支持导入 ComfyUI API prompt（含 `prompt` 包装）及版本 1 的 `lmbox-video-workflow` 文档；ComfyUI 界面专用的节点文档需先导出 API 格式。API 导出保留执行图，lmBox 文档同时保存节点位置。

ComfyUI V3 的 `COMBO` 与动态选项父字段使用目录提供的 choices。动态父字段下的点分隔输入保留 API 导入值并只读展示；改变父选项清除原分支的嵌套输入。嵌套参数通过导入 API JSON 设置，当前界面不声明完整动态分支表单；后端校验所选分支、类型和必需连接，并仅补全实际节点元数据中的默认值。

连线验证来源、输出索引、输入类型和无环性；删除节点移除关联输入连接。执行前验证完整必需输入、枚举及数值范围。API key、授权令牌等凭据字段由后端配置；导入携带凭据的工作流会拒绝，界面不能编辑或导出这些值。

草稿和任务状态存于当前 Pinia 会话，切换页签仅停止视图轮询，重新进入恢复查询。运行期间锁定输入，位置调整不改变执行输入版本。开始、状态和取消响应必须匹配工程、请求、输入版本与任务身份，旧响应不能覆盖新任务；取消请求不能自行推断已取消。只有后端登记的产物可预览或下载，临时预览 URL 在替换和卸载时释放。

启动响应丢失时保留原请求快照并锁定输入，用户通过“确认任务状态”重发相同请求标识，由 Rust 幂等恢复任务；不能自动用新标识重试。平台明确请求尚未发送时解除锁定，允许修改过大的输入。完整页面重载不声明恢复草稿或任务；请求命名空间由平台生成。

## 验证

`lib/domain/workflow/tests` 通过 domain 公开入口验证导入往返、端口和循环拒绝、凭据拒绝、任务锁定及过期响应。运行 `npm run lint:boundaries`、`npm run test`、`npm run build`，浏览器验收归统一 `npm run check`。

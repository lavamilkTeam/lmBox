# 前端：账户弹窗外观

先读 [前端结构](../../agent-frontend.md) 与 [外观规范](../agent-frontend-ui.md)。`index.ts` 公开 `AccountDialog`，复用共享 shadcn 的 Dialog、Tabs 和表单控件，包含圆形“请登陆”触发按钮及登录/注册表单。

组件仅维护弹窗开关、表单草稿与交互校验；不请求账户服务、不持久化凭据、不保存登录身份。邮箱和密码必填，注册还需邮箱验证码并校验确认密码一致。`submit` 发送模式、邮箱、密码与注册验证码，`requestCode` 在邮箱格式有效时发送邮箱，`reset` 请求清除调用方错误；外部错误通过 `error` 展示。切换模式清空密码和验证码，关闭时清空全部字段；复用 Dialog 的焦点约束、Escape 关闭和触发器焦点归还。

微信、QQ、GitHub 入口通过 `providerAction` 发送提供方与 `login`/`bind` 动作；注册页绑定为可选，不作为注册提交条件。UI 不跳转到授权地址，不模拟验证码发送、倒计时或已绑定状态。

私有 `ProviderButtons` 复用圆形按钮与 Tooltip，以本地品牌 SVG 呈现入口，并保留无障碍名称。注册页放在验证码之后、注册按钮之前；登录页放在登录按钮下方。素材来源与许可见 `lib/assets/NOTICE` 和 `LICENSE`，由 Vite 一并输出到发布许可证目录。

应用层接入统一账户服务；尚未接入时提供明确失败说明，不能伪报注册或登录成功。验证运行 `npm run check`，检查模式切换、校验、关闭清空、焦点归还及窄屏布局。

# 前端：共享功能列表与节点画布

先读 [前端结构](../../agent-frontend.md)。`index.ts` 公开 `FlowLibrary`、`FlowCanvas`、`FlowWorkspace`，私有组件、视图类型与样式归 `lib/`。由引导模块使用，不导入领域状态、协议或平台。

`FlowWorkspace` 提供左列表、右画布布局并加载限定于该布局的样式。`FlowLibrary` 接收显示目录，支持搜索、按钮添加与原生拖放；标题与可访问名称可配置。名称使用纯文字，不加装饰图标和常驻说明。

`FlowCanvas` 接收节点、边与可访问名称，只负责滚动、缩放坐标换算、指针/键盘移动、连接预览、选择与删除事件。`insertionPoint()` 提供当前视口中的添加位置。节点默认单输入、单输出；`inputPorts` 提供命名输入，边的 `targetPort` 指定输入端；连接事件传回端口名，连接规则由调用方验证。`nodeHeight` 与 `node-body` 插槽支持卡片内容；`node` 插槽替换整个节点外观并接收移动、结束移动、键盘移动及移除回调。未提供 `node` 插槽时沿用引导卡片。节点可传入宽高和 `ports` 的本地输入/输出坐标，画布不推断领域符号几何。`dropAnchor` 配置拖入时的光标偏移。

`wireStyle` 默认使用带箭头曲线，可选择无箭头水平/垂直折线。输出端既支持点击开始连接，也支持按住拖向输入端；指针捕获后通过当前屏幕位置命中本画布输入端，松开或取消时清理临时拖动。端口与连线端点使用同一坐标计算。每个画布生成独立 SVG marker ID；外部删除节点或边时清理失效选择。拖动使用 pointer capture，释放/取消后终止。Escape 取消连线，方向键移动节点，选中连线可用 Delete/Backspace 删除；缩放和删除控件叠放在画布上。

默认功能卡片为 232 × 88 px，标题与底部操作区不添加分隔线。`emptyTitle` 和 `emptyDescription` 可提供空画布的两行文案，只在没有节点时显示，不拦截拖放。画布使用纯色背景；缩放及坐标换算由画布统一处理，重置返回 100%。

通过 `npm run check` 验证引导回归及端口连接、缩放、拖动、键盘、删除及窄屏行为。

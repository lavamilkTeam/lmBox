# 前端：辅助说明

先读 [语言说明](../../agent-frontend.md)；维护规则与隐私要求见根规范。

## 职责与边界

公开 `HelpTip`，封装问号触发器、提示位置与键盘行为。

插槽内容由调用方提供，只处理显示和可访问性，不访问模型参数或业务状态。实际失败与确认对话框不藏进辅助提示。

## 行为约束

- 参数与预览的辅助说明通过 `ui/help-tip` 公开入口显示圆圈问号，悬停或键盘聚焦显示提示框，Escape 关闭。该组件只负责通用显示和可访问性，业务文案及动态数值由调用方提供；实际失败、图层诊断和确认对话框仍直接显示。

## 验证

统一检查见 [语言说明](../../agent-frontend.md#验证与维护)。验证悬停与键盘聚焦内容、Escape 关闭和提示可访问性。

# 前端：通用图标按钮

先读 [语言说明](../../agent-frontend.md)；维护规则与隐私要求见根规范。

## 职责与边界

公开 `IconButton`，封装透明底、浅悬停阴影、圆角提示框与键盘可访问性。

图标用默认插槽；`label` 为无障碍名称，`tooltip` 为文案或同名自定义插槽，`placement` 控制方向。只传递操作事件；禁用不触发动作，Escape 关闭提示，避免原生 title 与自定义提示重复。

## 行为约束

- 带提示的图标按钮通过 `ui/icon-button` 公开入口复用 `IconButton`，统一透明底、悬停淡阴影与灰色圆角提示框。调用方提供 `label` 无障碍名称、`tooltip` 文案（默认使用名称）、图标默认插槽，可通过 `tooltip` 插槽自定义非交互提示内容及 `placement` 调整方向。组件负责键盘聚焦、Escape 关闭、禁用状态与提示定位；点击事件和业务行为由调用方处理。

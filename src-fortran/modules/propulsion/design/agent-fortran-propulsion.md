# Fortran：喷管与喷注器初步计算

先读 [Fortran 说明](../../../agent-fortran.md)。本模块是项目自有计算内核，适用仓库 LICENSE；不修改或复制 NASA CEA 内核。所有设计数值计算、物理参数有效性校验及数值异常检测归 Fortran，Rust 仅协调 CEA 调用、传参和封装结果。

## 边界与入口

`source/types.f90` 定义模块数值类型及 C 布局；`nozzle.f90` 管喷管尺寸/型面，`injector.f90` 管液体通道水力计算，`api.f90` 暴露唯一跨语言入口。公开声明为 [include/propulsion.h](include/propulsion.h)，`bind(C)` ABI 版本 1。无文件、数据库、工程状态或前端依赖；CEA 出口数据由 Rust 应用层从同次请求的真实计算结果传入。

C 调用方拥有所有内存，指针须非空、缓冲区须符合头文件长度；无跨 ABI 分配、全局可变状态、STOP 或 stdout。返回 0 成功，1 失败；消息缓冲固定 256 字节并以 NUL 结束。失败必须丢弃全部数值输出。轮廓容量不足在写点前失败，点数上限 4097。GNU 构建使用递归局部存储和边界检查，避免并发共享临时变量。不得启用破坏有限数检查的 fast-math。

## 数值模型与依据

请求与结果均用 SI，角度字段明确用度；不照抄书中的混合单位系数。

喷管取真实 CEA 的 `c*`、匹配背压时的动量推力系数 `Cf,m` 与出口压力 `pe`，计算 `At=mdot*c*/pc`、`Ae=epsilon*At`、`rt=sqrt(At/pi)`，`Cf=Cf,m+(pe-pa)*epsilon/pc`、`F=mdot*c*Cf`、`Isp=c*Cf/g0`，`g0=9.80665 m/s²`。压力推力关系见 [NASA Glenn](https://www.grc.nasa.gov/www/BGH/rktthsum.html)。喉部流量系数取 1；全部性能为理想一维附着流，不含型面、黏性、冷却和有限速率反应损失。过膨胀输出提示，不据此预测分离或侧向载荷；非正推力系数返回错误。

型面只覆盖喉部到出口的扩张段内壁。圆弧坐标为 `x=R*sin(theta)`、`r=rt+R*(1-cos(theta))`，与后段相切。

- 锥形：圆弧终点沿给定半角的直线延伸至出口半径。几何效率估计 `(1+cos(alpha))/2` 仅单独返回，不乘到理想推力上。
- 参数化钟形：调用方给长度/喉径半径比及首尾切线角。两条切线交点作为二次 Bezier 控制点；终点固定为出口。要求控制点位于入口/出口之间、曲线轴向和径向单调；不自动套用 Rao 角度图表、不声称最大推力或特征线法优化。

书籍依据为《液体火箭发动机设计（上）》4.6.1，印刷页 404–407（PDF 页 431–434），图 4-38、4-42 和式 4-39。Bezier 构造是本模块明确选择的几何近似，不是书中最大推力求解器。

喷注器只做双液体组元的独立通道初算：由总质量流量和 O/F 分配两路；给定每路密度、动力黏度、压降、流量系数 `Cd` 和相同元件数量。用 `mdot=Cd*A*sqrt(2*rho*dp)` 求面积，`v=Cd*sqrt(2*dp/rho)`；圆孔直径由面积计算，环隙由给定内径求外径。`Re=rho*v*Dh/mu`；环隙水力直径为外径减内径，计算采用有理化差值保留薄间隙精度。

书籍依据为同书 4.4.1.1，印刷页 355–356（PDF 页 382–383），式 4-3 与适用条件。该模型假设稳态、不可压、单相、无汽蚀、等流量分配；Cd 和物性由调用方提供，不从燃气 CEA 状态推断液体物性。不计算离心液膜、雾化、喷雾角、混合、喷注面布孔、燃烧稳定性或热/结构；独立环隙尺寸不代表已验证同轴组件装配。

## 验证

`npm run build:propulsion` 编译并执行 C ABI 容量/布局/错误契约检查；`npm run check:propulsion` 通过 Rust 公开入口验证真实 Fortran 库及 CEA，缺库失败。测试包含独立水力参考、守恒/缩放、NASA RP-1311 example 8 性能、三种化学模式、压力推力、钟形端点与切线、非法/极端值、并发及移动后的 CLI。完整后端构建为 `npm run build:backend`；三平台由现有 Fortran CI 矩阵执行，本地通过不等于三平台已通过。

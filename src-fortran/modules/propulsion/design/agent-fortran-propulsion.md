# Fortran：喷管与喷注器初步计算

先读 [Fortran 说明](../../../agent-fortran.md)。本模块是项目自有计算内核，适用仓库 LICENSE；不修改或复制 NASA CEA 内核。所有设计数值计算、物理参数有效性校验及数值异常检测归 Fortran，Rust 仅协调 CEA 调用、传参和封装结果。

## 边界与入口

`source/types.f90` 定义模块数值类型及 C 布局；`nozzle.f90` 管扩张段尺寸/型面，`chamber.f90` 管筒段与收敛段内轮廓，`injector.f90` 管液体通道水力计算，`api.f90` 暴露唯一跨语言入口。公开声明为 [include/propulsion.h](include/propulsion.h)，`bind(C)` ABI 版本 1。无文件、数据库、工程状态或前端依赖；CEA 出口数据由 Rust 应用层从同次请求的真实计算结果传入。

C 调用方拥有所有内存，指针须非空、缓冲区须符合头文件长度；无跨 ABI 分配、全局可变状态、STOP 或 stdout。返回 0 成功，1 失败；消息缓冲固定 256 字节并以 NUL 结束。失败必须丢弃全部数值输出。轮廓容量不足在写点前失败，扩张段点数上限 4097，上游点数上限 6146。GNU 构建使用递归局部存储和边界检查，避免并发共享临时变量。不得启用破坏有限数检查的 fast-math。

## 数值模型与依据

请求与结果均用 SI，角度字段明确用度；不照抄书中的混合单位系数。

喷管取真实 CEA 的 `c*`、匹配背压时的动量推力系数 `Cf,m` 与出口压力 `pe`，计算 `At=mdot*c*/pc`、`Ae=epsilon*At`、`rt=sqrt(At/pi)`，`Cf=Cf,m+(pe-pa)*epsilon/pc`、`F=mdot*c*Cf`、`Isp=c*Cf/g0`，`g0=9.80665 m/s²`。压力推力关系见 [NASA Glenn](https://www.grc.nasa.gov/www/BGH/rktthsum.html)。喉部流量系数取 1；全部性能为理想一维附着流，不含型面、黏性、冷却和有限速率反应损失。过膨胀输出提示，不据此预测分离或侧向载荷；非正推力系数返回错误。

扩张段型面覆盖喉部到出口的内壁；可选燃烧室几何在同一喉部基准上补全上游内轮廓。圆弧坐标为 `x=R*sin(theta)`、`r=rt+R*(1-cos(theta))`，与后段相切。

- 锥形：圆弧终点沿给定半角的直线延伸至出口半径。几何效率估计 `(1+cos(alpha))/2` 仅单独返回，不乘到理想推力上。
- 参数化钟形：调用方给长度/喉径半径比及首尾切线角。两条切线交点作为二次 Bezier 控制点；终点固定为出口。要求控制点位于入口/出口之间、曲线轴向和径向单调；不自动套用 Rao 角度图表、不声称最大推力或特征线法优化。

书籍依据为《液体火箭发动机设计（上）》4.6.1，印刷页 404–407（PDF 页 431–434），图 4-38、4-42 和式 4-39。Bezier 构造是本模块明确选择的几何近似，不是书中最大推力求解器。

### 可选燃烧室与收敛段

新增 C 入口 `lmbox_chamber_calculate_v1`，原 ABI 1 的结构和符号保持不变。输入筒段内径及长度，接收同次喷管结果的喉半径与扩张段长度；统一喉部 `x=0`，上游 `x<0`。返回筒段、收敛段、总长、收缩面积比、圆弧半径、连接/控制点和上游采样点，最后一点与喷管第一点一致。仅为内流道几何，不改变 CEA 无限面积燃烧室的理想性能假设。

令径向落差 `d=Rc-rt>0`，圆弧连接切线角为 `θ`（严格在 0–90°）：

- `filletedCone`：入口半径 `a`、喉前半径 `b` 的两圆弧与直锥相切；直锥轴向长度 `h=[d-(a+b)(1-cosθ)]/tanθ` 必须为正，收敛总长为 `(a+b)sinθ+h`。入口与喉部切线平行轴线。
- `tangentArcs`：无直锥的双圆弧，调用方指定 `b/(a+b)` 严格在 0–1；`a+b=d/(1-cosθ)`，由此确定两半径及长度。连接点两侧切线一致，不保证曲率连续。
- `cubicBezier`：给定收敛长 `L` 与正控制柄比例 `u,v`，要求 `u+v≤1`。四控制点为 `(-L,Rc)`、`(-L+uL,Rc)`、`(-vL,rt)`、`(0,rt)`。端部切线平行轴线，曲率不约束；不是任意端角或最优型面求解。

圆弧-直线形式对应上述书籍 4.6.1.1；双圆弧及三次曲线是本模块明确规定的参数化几何，不声称覆盖书中全部分类。收敛段至少 4、至多 2048 个分段/曲线；验证有限数、轴向严格单调、半径非增和缓冲容量，不指定弦高误差或制造公差。结构材料、壁厚、冷却、连接和热/强度校核不由这些内轮廓确定。

喷注器只做双液体组元的独立通道初算：由总质量流量和 O/F 分配两路；给定每路密度、动力黏度、压降、流量系数 `Cd` 和相同元件数量。用 `mdot=Cd*A*sqrt(2*rho*dp)` 求面积，`v=Cd*sqrt(2*dp/rho)`；圆孔直径由面积计算，环隙由给定内径求外径。`Re=rho*v*Dh/mu`；环隙水力直径为外径减内径，计算采用有理化差值保留薄间隙精度。

书籍依据为同书 4.4.1.1，印刷页 355–356（PDF 页 382–383），式 4-3 与适用条件。该模型假设稳态、不可压、单相、无汽蚀、等流量分配；Cd 和物性由调用方提供，不从燃气 CEA 状态推断液体物性。不计算离心液膜、雾化、喷雾角、混合、喷注面布孔、燃烧稳定性或热/结构；独立环隙尺寸不代表已验证同轴组件装配。

## 验证

`npm run build:propulsion` 编译并执行 C ABI 容量/布局/错误契约检查；`npm run check:propulsion` 通过 Rust 公开入口验证真实 Fortran 库及 CEA，缺库失败。测试包含独立水力参考、守恒/缩放、NASA RP-1311 example 8 性能、三种化学模式、压力推力、钟形端点与切线、三类收敛段的独立长度参考/相切/共喉基准、非法/极端值、并发及移动后的 CLI。完整后端构建为 `npm run build:backend`；三平台由现有 Fortran CI 矩阵执行，本地通过不等于三平台已通过。

# Rust：业务组装与任务

先读 [语言说明](../../agent-rust.md)；维护规则与隐私要求见根规范。

## 职责与边界

通过 `app::build_preview`、`build_bundled_preview` 和 `PreviewTasks` 公开入口组装用例、注入执行者并协调任务。

依赖各 feature/runtime/contracts 的公开接口，不复制解析与制造算法。持久工程、队列、缓存和切片尚未实现，下述相关约束是后续实现要求，不代表已有功能。

## 行为约束

- Rust 是工程数据事实来源。导入时保存受控源文件副本及标识，工程持久化记录来源、设置与产物引用；不能只保存文件名或前端 File 对象。

- 区分预览显示设置、模型设置和切片设置。网格开关、相机和透明度等显示变化不触发几何任务；模型或切片输入变化按各自依赖使结果过期。

- 每个任务关联工程 ID、任务 ID 和输入修订号/指纹。完成时核对工程仍存在且输入仍匹配，过期任务不得覆盖当前模型，多标签任务不得串写。

- 定义排队、运行、成功、失败、取消等状态及合法转移。取消和超时须传达给实际 worker/切片器，等待进程回收并清理临时输出；不能只修改界面状态。

- 模型缓存键包含源内容/IR 指纹、模型设置、算法与协议版本、容差；切片缓存另包含模型指纹、切片器版本与配置。不能用文件名或修改时间单独判定复用。

- 切片可调用成熟外部引擎，由 `runtime/slicer` 负责进程和配置适配、`features/slicing` 负责业务用例。未接入真实切片器时不得生成伪 G-code，也不得将示例路径称为用户切片结果。

- 工程与产物通过受控 ID 定位。来自 UI 或 worker 的路径不能直接获得任意读写权限；导出到用户选择的目标通过桌面文件接口完成。

- 保存应原子替换并带格式版本；版本迁移规则在 `features/project` 内完成，通过 `runtime/storage` 接口落盘，避免 UI 直接修改磁盘工程结构。

- `bin/preview.rs → app::build_preview → features/stencil + runtime/python`；应用层协调业务验证和外部进程，feature 不访问文件或启动 Python。

- 原生测试需要先运行 `npm run setup:geometry`。本入口面向本地开发预览，桌面宿主另经 commands 接入，不表示已完成工程持久化。

- 前端每次导出带新的任务身份并核对当前修订；取消、超时、并发数和 32 MB 产物限制同模型预览。桌面宿主与本地开发适配复用同一业务入口，未增加持久任务仓库。

- `desktop/tauri` 通过 `app::PreviewTasks` 和 `app::build_bundled_preview` 复用核心行为。IPC、原生对话框和固定资源定位归宿主，协议验证与进程执行归核心。
- `app::PreviewTasks` 登记最多两个任务，按工程/任务身份隔离。准备期间的取消须保留，运行中任务由实际执行者收尾；未启动登记在一分钟后可回收。任务生命周期测试留在核心。
- 打包后的 worker 集成测试位于桌面宿主；核心测试只依赖源码 Python 环境，不要求 WebView、Tauri 或打包资源。桌面构建与发布见 [宿主说明](../../../desktop/tauri/agent-rust.md)。

- 通过模块公开行为测试解析结果、工程状态和任务结果；外部文件/进程在有替换需求的接口处隔离，不模拟内部调用细节。

- 验证导入资源限制、保存恢复、worker 异常、取消超时、乱序任务结果、多工程隔离及缓存失效。用真实支持范围内的样例贯通导入、解析与 Python 调用。

- 新增能力时同步记录实际支持范围与验证结果。

## 验证

统一检查见 [语言说明](../../agent-rust.md#验证与维护)。验证任务登记上限、工程/任务身份隔离、准备期取消、退出清理、超时和真实 Python 集成。

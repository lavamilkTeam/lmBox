# Rust：Gerber 解析器

先读 [语言说明](../../../../agent-rust.md)；维护规则与隐私要求见根规范。

## 职责与边界

覆盖 lexer、format、state、aperture、expression、error；解释坐标、命令状态与宏表达式。

属于 board_import 私有实现，不能被其他模块直接导入或为测试公开。使用结构化 IR 保留源定位、单位、圆弧、极性和顺序，不生成制造轮廓或截图。

## 行为约束

- D01/D02/D03 模态、G54、G74、极性和全图重复的支持限制见上层导入模块；修改语法实现时同步核对其支持范围，不能静默放宽。

# Rust：数字逻辑仿真

先读 [Rust 结构](../../../agent-rust.md) 和 [数字逻辑协议](../../../../contracts/schemas/v1/agent-contracts-digital-logic.md)。`mod.rs` 仅公开 `Simulator::new`、`Default` 和 `request`；原生与 WASM 共用此入口。模块只依赖标准库与共享协议，不访问前端状态、文件、网络、系统时钟或其他业务模块。

## 职责与状态

- `simulation.rs` 管理独立工程会话、请求版本、逻辑 tick、统一采样和响应快照。首次成功 load 绑定工程；命令接受相同或更新的输入版本，旧版本和跨工程请求失败。每次请求在副本上执行，全部成功后替换会话，失败不改变状态或版本。
- `circuit.rs` 校验节点、端口、单驱动和拓扑，提供四态组合求值。组合回路必须被 D 触发器状态切断；输入源、时钟、逻辑门和 D 触发器有单输出，探针和 LCD 没有输出。
- `lcd.rs` 拥有 HD44780 的逻辑写入接口、半字节组装、DDRAM 和显示状态。外观、字符绘制和用户交互归前端，不在此模块实现。

load 重建状态；未指定的输入源为 0，时钟为 0，D 触发器 Q 为 X，LCD 清空并关闭。reset 恢复最近 load 的初始输入值与这些初始状态。set_input 仅允许输入源的 0/1 值，传播逻辑但不增加 tick。每个 step tick 同时翻转所有时钟。

## 求值语义

未连接输入为 Z。普通逻辑门把 X/Z 当作不确定输入，其中 AND 的 0、OR 的 1 可决定输出；BUF 不是三态驱动器，Z 输入得到 X。探针通过响应的 `inputs` 观察其 A 端。LCD 在 4 位模式下不对闲置的 D0–D3 报悬空诊断，其实际输入仍返回 Z。

每轮先按拓扑顺序计算组合逻辑，再用同一快照在确定的 CLK 0→1 沿采样所有 D 触发器，随后统一更新 Q。D 为 X/Z 时采样为 X。load/reset 只建立 CLK/E 基线，不合成跳变。由 Q 引发的新时钟沿继续按相同规则传播，直到稳定；仅含 D 端反馈的电路可以工作，无法稳定的时钟反馈明确失败。输入和节点提交顺序不改变结果。

节点/连线上限为 512/4096，单次步进为 1–1000 tick。传播最多 1024 轮，每个请求最多 200 万次节点求值；超限原子失败。tick 和版本不超过 JavaScript 安全整数范围，身份与字段限制见协议。诊断按节点汇总，每个节点最多一条。

## HD44780 范围

依据 [HD44780U 数据手册](https://www.sparkfun.com/datasheets/LCD/HD44780.pdf) 的寄存器、4/8 位接口、指令和初始化流程实现逻辑子集：E 确定下降沿写入，RS 选择指令/数据，R/W 必须为 0。8 位模式使用 D0–D7；4 位模式高半字节先传，每次使用 D4–D7。上电或收到有效功能设置后，3、3、3、2 半字节同步序列允许低四位未接线；已运行的 4 位接口可重新同步，未发送清屏时保留 DDRAM。其他完整指令和数据按当前总线宽度接收，数据含 X/Z 仍拒绝。半字节之间 RS 不一致或总线不确定时丢弃不完整传输并给出诊断。

支持清屏、归位、显示/光标开关、地址增减、写入伴随显示移位、显式光标/显示移位、功能设置和 DDRAM 地址。两行模式每行有 40 个存储位置，地址为 0x00–0x27、0x40–0x67，显示前 16 列并考虑移位；单行模式使用 0x00–0x4F，只呈现第一行。可见光标以 0–31 的行优先位置返回，不可见时为 null。关闭显示保留 DDRAM。

字形支持 A00 ROM 的 0x20–0x7F 常用字符子集（包含 0x5C 的日元符号及末尾左右箭头）；其他字形显示替代字符并诊断。读取、忙标志、双向数据总线、CGRAM、自定义字形、5×10 模式和光标闪烁时序未实现；CGRAM 写入不会误写 DDRAM，5×10 模式不提供字符显示结果。tick 是逻辑步进，不代表传播延时、指令执行耗时、真实电压或物理电路验证。

## 验证

`src-rust/tests/digital_logic.rs` 通过模块公开入口覆盖四态门表、悬空、顺序独立性、同拍触发器、时钟级联与反馈、请求拒绝原子性、边界限制、LCD 真实控制/数据输入序列，以及响应对共享 schema 的兼容性。运行 `cargo test --manifest-path src-rust/Cargo.toml --locked --test digital_logic`，并执行 [Rust 总体验证](../../../agent-rust.md#验证与维护)。

# 前端：参数导出

先读 [语言说明](../../agent-frontend.md)；维护规则与隐私要求见根规范。

## 职责与边界

`useParameterExport` 保存当前工程参数，处理保存取消、错误和成功反馈；按钮外观归 `ui/export-button`。

仅保存参数 JSON；不冒充包含源文件的完整工程保存。经 platform 落盘，只在保存确实成功后记录日志。模型导出由应用协调当前模型任务，不混入此 feature。

## 行为约束

- 参数 JSON v2 额外保存图层选择、建模设置及编辑覆盖，不包含源文件，也不是完整工程存储。预览算法版本随结果记录。

## 验证

统一检查见 [语言说明](../../agent-frontend.md#验证与维护)。验证参数 JSON 内容、保存取消不记成功、无当前工程禁用和保存失败反馈。

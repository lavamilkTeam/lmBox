# 前端：导入

先读 [语言说明](../../agent-frontend.md)；维护规则与隐私要求见根规范。

## 职责与边界

`BoardImport` 连接文件选择与 `ui/import-button`；`useBoardImport` 执行导入、更新工程、反馈结果并取消任务。

经 domain/platform 公开入口处理业务，不解析原文件，不自定义图标、颜色或样式。DOM 文件选择触发可由入口组件捕获；字节读取与原生选择 API 留在 platform。卸载取消实际任务；快捷键、拖放及其他 feature 的导入请求由 app 连接。

## 行为约束

- 首次导入优先显示可解析的锡膏层，也允许选择板框、铜层和失败图层查看诊断。板框以独立颜色叠加；显示范围用于画布适应，不冒充真实板框尺寸。

## 验证

统一检查见 [语言说明](../../agent-frontend.md#验证与维护)。验证点击/快捷键选择文件、重复导入、无效图层、失败与实际任务取消。

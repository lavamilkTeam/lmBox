# 前端：浏览器集成测试

先读 [语言说明](../frontend/agent-frontend.md)；维护规则与隐私要求见根规范。

## 职责与边界

覆盖工作台公共行为与真实 Rust/Python 链路；夹具来自仓库，配置见 `playwright.config.ts`。

通过可见界面、下载和公开适配测试，不导入 feature 私有实现。UI 样式调整不新增复述 CSS 的测试；必要时验证焦点、提示、操作、取消和多文档隔离。

`installer.pw.ts` 使用独立安装预览服务验证静止入场后才请求 GIF、减少动态效果和窄屏按钮交互；两个前端服务由 Playwright 的 `webServer` 配置启动。

## 行为约束

在仓库根目录运行 `npm run check`。测试公共行为：多标签隔离、文件导入、视图切换、参数更新、关闭确认、事件取消及错误处理。后续原生接口测试使用 platform 适配替身，不直接 mock feature 私有实现。

- CI 使用 Chromium 软件 WebGL 运行真实建模测试，禁止 `test.only`、不通过重试掩盖失败，并保留失败 trace/截图。前端门禁覆盖边界、单元、类型、构建和端到端行为。

## 验证

统一检查见 [语言说明](../frontend/agent-frontend.md#验证与维护)。执行完整浏览器套件，保留失败 trace/截图；真实计算采用两个 worker，不用重试掩盖失败。

`propulsion.pw.ts` 验证功能页签、真实 Fortran 锥形/钟形和液体圆孔/环隙计算；暂未开放的喷注器通过仅供测试的 `fixtures/propulsion-harness.html` 挂载模块公开入口，保持真实服务、草稿恢复和迟到响应验证，不进入生产构建。其余覆盖包括三类收敛段、SVG 转义与 DXF 毫米坐标、JSON 导出身份配对、参数失效、迟到响应、错误恢复、模块返回和窄屏。运行前先构建 `npm run build:backend`；不以计算 mock 替代正常路径。

`cfd-native.pw.ts` 仅在 `LMBOX_CFD_INTEGRATION=1` 时运行，`LMBOX_CFD_TEST_FILE` 指向公开来源的纯几何 CAD 夹具。通过真实原生会话验证导入、物理模型动态控件、单位输入、属性回写与 FCStd 保存，并关闭测试自身的会话；不替换后端响应。

`guide.pw.ts` 覆盖默认启动、功能搜索与拖放、缩放坐标、指针和键盘移动、连线、删除及返回后的会话草稿。现有工作区测试通过 `workspace-navigation.ts` 从功能库打开功能，已打开的工作区直接通过顶部页签切换；引导测试另覆盖固定入口、重复打开、关闭相邻页签、焦点与窄屏溢出。

`digital-logic.pw.ts` 验证共享列表与画布在逻辑门编辑页面的图片加载、单/双输入端、输出点拖到输入点、引脚和连线端点对齐、缩放拖放、键盘移动/删除、输入端占用校验和连线删除；页签切换及关闭后保留电路草稿，刷新重置，且不混入引导流程草稿。不声明逻辑求值或时序仿真已完成。

逻辑门说明覆盖问号点击与添加隔离、键盘打开、Escape/关闭按钮及焦点归还，弹窗内按键不修改电路，并验证窄屏弹窗可见范围。

教学动画逐一验证八种逻辑门的 GIF 对应关系与真实图片加载；未打开说明时不请求图片，关闭后移除图片元素。

`cfd-lifecycle.pw.ts` 在 HTTP 适配边界使用可辨识替身，仅验证页签关闭确认、失败保留、重试释放、重新初始化，以及等待在途请求后使用最新版本关闭；不声称验证原生流体求解。

`ai-workspaces.pw.ts` 使用真实 Rust AI CLI、Python 适配与 LangGraph，仅将外部 ComfyUI/云端模型替换为明确标注的本机服务夹具；覆盖节点连线/API 导出、凭据隔离、任务切换、取消、真实工具写文件与产物下载。运行前执行 `npm run setup:ai`。该验证不代表真实云端模型已调用。

Agent 对话验收覆盖连续追问的真实历史、旧轮次产物下载、新建对话隔离、发送/换行/输入法组合，以及窄屏设置操作；外部模型夹具验证收到的历史，不能只检查聊天气泡。
